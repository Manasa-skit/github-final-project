# Simple Interest Calculator

## Project Description
This repository contains a simple interest calculator written as a Bash shell script (`simple-interest.sh`). It takes user inputs for the principal amount, annual rate of interest, and time period in years to compute the simple interest.

## Formula Used
Simple Interest = (Principal × Rate × Time) / 100
